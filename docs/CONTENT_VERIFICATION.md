# Content verification

Every piece of text on the site falls into one of three buckets. This document lists where each lives in the code so the client can review it quickly, and what still needs their confirmation before launch.

| Bucket | Meaning | Where in code |
|---|---|---|
| **Source-backed** | Copied from the client PDF (verbatim, hyphenation removed) | `src/data/products.ts`, `src/content/company.ts`, `sourceNote` / `sourceHeading` in `src/data/categories.ts`, `sourceMentions` in `src/data/regions.ts` |
| **Derived** | Computed from source data (counts, code lists, size summaries, "Tutti i 37 codici") | components, at render time |
| **Editorial** | Written for the website; describes atmosphere, never product facts | `src/content/site.ts`, `tagline` / `intro` in `src/data/categories.ts`, `territories` in `src/data/regions.ts`, `line` (non-quoted) in `src/content/showcase.ts` |

## Source-backed content

### Products — `src/data/products.ts`
- 206 product families / 276 code occurrences (275 unique), cross-checked automatically against every code printed in the PDF (0 missing, 0 extra). See [CATALOG_EXTRACTION_REPORT.md](CATALOG_EXTRACTION_REPORT.md).
- Names are kept exactly as printed in `sourceName` (shown on every product page as "Nome in catalogo"). The site displays a sentence-case version generated by `src/lib/text.ts`; five records override the display name (quotes, BIO).
- Every product page shows its PDF page, a verification badge (*Dati verificati / parziali / da confermare*) and the notes recorded for that record, so the client can audit on the live prototype.

## Deliberately not claimed

- No DOP/IGP labels, certifications, awards (other than the quoted Alma Caseus line), founding date, staff, facilities or company history for Noi, la qualità.
- No prices, availability, ratings, reviews or testimonials.
- No origin for products whose source text does not state one.
- Photos from Unsplash are used only in editorial blocks and category atmospheres, never as product images. Product images are always PDF crops, labelled with their page and, where shared, as *immagine di gamma* / *comune ai formati*.
